## Introduction
This project focuses on predicting the movement of gold prices using technical indicators such as the Moving Average (MA) and Volume Weighted Average Price (VWAP), combined with the Gradient Boosting Algorithm. This method aims to provide more accurate predictions by leveraging historical data and sophisticated machine learning techniques.

## Prerequisites
Before you begin, ensure you have met the following requirements:
- You have installed Python 3.7 or higher.
- You have a basic understanding of machine learning concepts.
- You have installed the necessary libraries such as pandas, numpy, scikit-learn, and matplotlib.

## Methodology
### Data Collection
The data used for this project is historical gold price data obtained from reliable financial sources.

### Data Preprocessing
The data is cleaned and preprocessed to handle missing values, normalize the data, and create new features based on the Moving Average and VWAP.

### Model Training
The Gradient Boosting Algorithm is used to train the model. Various hyperparameters are tuned to achieve the best performance.

### Evaluation
The model's performance is evaluated using metrics such as Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE).
